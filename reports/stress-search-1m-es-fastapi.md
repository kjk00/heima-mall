# 1000000 件商品搜索压力测试

测试时间：2026-11-19T05:02:31.114664+00:00。Python 3.12.15，macOS-15.7.7-arm64-arm-64bit，8 核。后端：in-process ASGI (FastAPI) + SQLite。搜索引擎：elasticsearch。

独立临时 SQLite 数据库，商品 1000000 件（其中含关键词「耳机」的同类商品 1200 件，唯一目标商品 1 件）。通过真实请求入口（stdlib 为 WSGI 多线程，fastapi 为 ASGI 异步并发）调用 GET /api/products，保留参数校验、搜索走 Elasticsearch（wildcard 查询，事务 outbox→RabbitMQ 同步链路已建索引），命中 id 回表取最新行；COUNT 统计、分页与店铺信息装配；未启用 Redis 目录缓存，测得的是搜索引擎本身的速度；不包含 TCP 与前端渲染。每档并发预热后计数。

## 场景说明

- 唯一商品搜索：1000000 件商品中按名称定位唯一商品（q=星陨限定礼盒，命中 1 件）。
- 同类关键词搜索：关键词搜索同类商品（q=耳机，命中 1200 件，取第 1 页）。
- 无关键词浏览（对照）：不带关键词的目录浏览，作为搜索开销对照。

## 复现命令

```bash
ELASTICSEARCH_URL=http://127.0.0.1:9200 RABBITMQ_URL=amqp://guest:guest@127.0.0.1:5672/ DATABASE_BACKEND=sqlite .venv/bin/python scripts/stress_search.py --backend fastapi --products 1000000 --group 1200 --concurrency 1 16 64 --requests 200 --only unique keyword browse --output reports/stress-search-1m-es-fastapi.json
```
